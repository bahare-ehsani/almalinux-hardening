# AlmaLinux Server Hardening

## Overview

This project documents the setup and hardening of an AlmaLinux server for production-ready deployment.

## Skills

* Linux (AlmaLinux)
* User & Group Management
* SSH Hardening
* Firewall Configuration (firewalld)
* SELinux
* Systemd Services
* Auditd
* Filesystem Security
* Sysctl Hardening
* Password & PAM Configuration
* Cron Security

## Structure

* `users-groups.md` – User and group management
* `ssh-hardening.md` – SSH configuration and authentication hardening
* `firewalld.md` – Firewall configuration and network access control
* `selinux.md` – SELinux verification and hardening
* `systemd.md` – Systemd service management and rsyslog hardening
* `auditd.md` – Linux auditing and security event monitoring
* `filesystem.md` – Filesystem and mount security review
* `sysctl.md` – Kernel network parameter hardening
* `password-pam.md` – Password and PAM security review
* `cron.md` – Cron service and scheduled job review
* `scripts/` – Automation scripts
