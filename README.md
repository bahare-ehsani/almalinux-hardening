# AlmaLinux Server Hardening

## Overview
This project documents the setup and hardening of an AlmaLinux server for production-ready deployment.

## Skills
- Linux (AlmaLinux)
- User & Group Management
- SSH Hardening
- Firewall Configuration (firewalld)
- SELinux
- Systemd services
- Logging and monitoring

## Structure
- `users-groups.md` – User and group management
- `ssh-hardening.md` – SSH configuration
- `firewalld.md` – Firewall setup
- `selinux.md` – SELinux verification
- `systemd.md` – Systemd service management
- `logs.md` – Logging and monitoring
- `scripts/` – Automation scripts
